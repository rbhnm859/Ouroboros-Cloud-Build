# V74 FR1 — 十二型態公平辨認與日內／週內研究

**研究用途；非正式交易策略。** 沿用正式分支 f786b90063a43a5a4dac35a86350ecd8e8b5d3cd，既有 V51 保護核心、所有交易風險門檻與歷史證據保持不變。

## 第一階段實際變更

1. 只在原有 V73 研究模式下，逐一記錄十二型態每個幾何假設從嘗試辨認、比例拒絕、完成匹配、時效通過、型態去重至實際返回研究池的分層數量。
2. 原始辨認判斷、比例門檻、反轉區域、最終候選截取與真實下單路徑完全不改動，確保可用來稽核每道過濾器影響。
3. 日內與週內預設資金風險分別為 0.5% 與 1%；預定收益資格為本金的 1.15% 與 2.3%；最低預計淨獲利／風險 2.3 倍。所有量化均使用已提供的券商契約單位、保證金及交易成本，不猜測手數等值。
4. 同事件重複交易、已持有其他交易、缺少報價或券商規格、時間先後矛盾時拒絕。此模組僅輸出候選資格，**不下單且不預言盈利**。
5. 使用原有 2016–2020 年已封存的 R18 資料重算歷史家族結果筆數，以 SHA256 嚴格驗證來源。該結果不是所有原始辨認數，更不是新策略績效。

## 工程停止條件

- 尚未測得每道過濾器對各型態供給數的實際影響以前，不在正式下單路徑刪除過濾器。
- 不因每個型態需要交易訊號，就要求所有型態強迫成交。
- 新的反轉區域必須先於 D 點獨立投射；需要從已知 X/A/B/C 計算，不能用 D 作預測中心。
- 日內與週內交易都不能跳過實際交易量、最小停損、保證金、費用、週末關市與資金占用檢查。
- 獲利百分比為事前預計門檻，不是每次實現報酬的保證。
- 封存 2021–2023 年正式驗收資料，不進行針對該區間的任何研究調參。
- 網格交易延後至既定後續版本；LibreChat、Railway、其他 cBot 不受影響。

## 本階段驗收與下階段

此提交若通過測試，只代表研究用觀測程式及資金規劃程式符合基本合約；**不代表十二型態供給改善或新策略績效提升**。

先用合法研究資料取得新舊辨認流程的每型態淘汰關卡統計；有證據後，才分離修改純辨認／預期反轉區域／策略決策，進行可重現的前後對照回測。正式商業年度門檻原封不動。
