# v0.3.0-fix5 research candidate

Not approved for profitability. Extends fix4 by reserving execution costs in volume sizing and minimum net reward/risk, and rejecting previously traded or older D indices in the same direction. Reserve defaults to 2 pips, explicitly assumed; gold test uses 40 pips. This is a modeled allowance, not a guaranteed loss cap against gaps. Spread is already reflected in quoted entry; reserve is additional allowance for commission and execution uncertainty. Three predefined cases: EURUSD H1/M15 and XAUUSD M15, USD 200 at 1% equity risk, 2026-06-08 through 2026-09-08. Cost scenarios remain EURUSD spread 1 pip / gold 30 pips and commission 35 USD/million, unverified against actual broker fees. Observed period is development data. No independent validation or live trading. Diagnostic artifact enables trading; checked-in source defaults off. Build and backtests completed in GitHub Actions run 34186495014: EURUSD H1 lost 1.30 USD over 1 trade, EURUSD M15 lost 3.96 USD over 3 trades, and XAUUSD M15 placed 0 trades.
