# Phase 2 implementation gates — source certification first

1. `P2-RULE-PROVENANCE`: for each of ten families, original author, exact edition/volume/page, Fibonacci alternatives, rule table, source SHA provenance; refuse if copyrighted books are not accessible to verify. Never invent pages.
2. `P2-PIVOT-GRAMMAR`: x/a/b/c/d causal confirmations, alternation + high/low semantic geometry and separate Shark 0-X-A-B-C / 5-0 extension grammars; D cannot be projected and complete simultaneously. Test exact timestamp/candle availability.
3. `P2-PRZ`: independently project XA/BC/AB=CD ranges from X/A/B/C before D, intersect bands and broker tick round. No future D inputs in candidate generation.
4. `P2-COMPLETION`: actual confirmed pivot D with window expiry, stop/invalidation and event dedup, not only ratio tolerance.
5. `P2-REJECTION-TESTS`: wrong direction, ratios outside bounds, zero/negative leg size, impossible PRZ, ties, same-side pivots, overlapping events and dataset chronology anomalies.
6. `P2-EVIDENCE`: exact committed source, unit/property tests, deterministic research replay, independent review. No promotion while `SourceVerified=false`.

All P2 work is confined to the new Cleanroom branch, and no V74 patch is allowed.
