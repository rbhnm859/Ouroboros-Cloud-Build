# V73 Supply Reconstruction 2 — AB=CD empirical eligibility

Run 6 proved the full parent-family lattice is working: parent-family causal supply rose materially, but remained 189–329/year while total causal outcomes were 840–1,099/year.

The prior V73/V74 tooling pre-blacklisted standalone AB=CD even though project governance explicitly allows it with empirical proof. This reconstruction corrects that methodological mismatch without lowering the 400/year physical-supply floor.

Rules:
- V73 requires >=400 total independent harmonic causal opportunities/year.
- It additionally requires >=150 parent-family opportunities/year and >=8 visible families.
- Standalone AB=CD is not automatically capital eligible.
- In each V74 OOF fold, AB=CD can enter the test year only if prior training windows already show N>=300, Mean R>0, PF_R>=1.20 and 95% LCB>0.
- Test-year outcome never controls AB=CD eligibility.
- Final DEV/Validation/Fresh eligibility is frozen from all pre-DEV 2016–2023 evidence.
- V74 aggregate gates remain unchanged: N>=250/year, Mean R>=0.90, PF_R>=3.30, WR>=70%, Avg RR>=2.30, LCB95>0.
